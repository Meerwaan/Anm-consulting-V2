# 00 — Les trois modules de contrôle (Sofia, 21/09/2026)

Texte dicté, recopié tel quel (« URSAF » et « Drakkar » corrigés en URSSAF et Dracar) :

> Il faut créer le module DGFiP en lien à toutes les vérifications possibles concernant les factures de complaisance et les factures fictives. Il faut créer le module contrôle URSSAF en lien avec toutes les vérifications contre le prêt de main-d'œuvre illicite, délit de marchandage, travail dissimulé et dissimulation d'activité. Il faut créer le module contrôle CNAPS avec les fiches qui sont déjà prévues par Dracar Ultimate, donc s'inspirer de Dracar Ultimate pour créer ce module de contrôle.
>
> Et adapter avec ce que nous avons déjà masqué pour que ça matche dans le fonctionnement.

## Ce que ça veut dire

- **DGFiP** : un module entier, toutes les vérifications possibles sur la facture de complaisance et la facture fictive.
- **URSSAF** : un module entier, toutes les vérifications contre le prêt illicite de main-d'œuvre, le délit de marchandage, le travail dissimulé et la dissimulation d'activité.
- **CNAPS** : un module bâti sur les fiches de Dracar Ultimate.
- **Ce qui a été masqué** (le parcours 360 par étapes et son référentiel de points de contrôle) est repris dans ces modules, avec le même fonctionnement que la sous-traitance : grille au toucher, alertes calculées, conclusions, actions correctives, rapport.
