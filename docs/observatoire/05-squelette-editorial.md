# Squelette éditorial — toutes les prises de parole d’ANM

Texte de Sofia, repris tel quel. Vaut pour LinkedIn, le site, l’Observatoire, TikTok, Reels, Shorts.

---

L’objectif est de conserver une ligne claire et cohérente dans le temps.

ANM Consulting ne doit pas être présenté comme un média généraliste de la sécurité privée.

## Promesse centrale

Aider les dirigeants de sociétés de sécurité privée à identifier leurs vulnérabilités avant qu’un contrôle CNAPS, URSSAF, DGFIP ou Inspection du travail ne les révèle.

Chaque publication doit donc amener le dirigeant à se poser une question simple :

« Est-ce que ce risque pourrait exister dans mon entreprise ? »

## Les cinq territoires éditoriaux

### 1. CNAPS

Thématiques : sous-traitance ; autorisations ; cartes professionnelles ; DRACAR / DRACAR Ultimate ; contrôle des dirigeants ; contrôle des agents ; devoir de vigilance ; sanctions ; retraits et suspensions ; décisions administratives ; jurisprudence TA, CAA et Conseil d’État.

Angle ANM : Ce que le CNAPS regarde réellement dans une entreprise.

### 2. URSSAF

Thématiques : travail dissimulé ; sous-traitance ; prêt de main-d’œuvre ; marchandage ; devoir de vigilance ; masse salariale ; volume d’heures ; salariés déclarés ; indépendants ; redressements ; solidarité financière.

Angle ANM : Les chiffres de l’entreprise sont-ils cohérents avec l’activité réellement réalisée ?

### 3. DGFIP

Thématiques : TVA ; factures fictives ; factures de complaisance ; sous-traitants ; réalité des prestations ; déductibilité ; incohérences comptables ; paiements ; fournisseurs ; justificatifs.

Angle ANM : Une facture comptabilisée n’est pas nécessairement une facture sécurisée.

### 4. Inspection du travail / social

Thématiques : durée du travail ; heures supplémentaires ; repos ; plannings ; prêt de main-d’œuvre ; travail dissimulé ; convention collective ; conditions d’emploi.

Angle ANM : Ce que les documents sociaux racontent réellement de l’organisation de l’entreprise.

### 5. Économie de l’entreprise de sécurité

Thématiques : heures vendues ; heures salariées ; sous-traitance ; prix horaire ; masse salariale ; marge ; coût réel d’un agent ; dépendance à la sous-traitance ; défaillances ; marchés publics ; rentabilité d’un contrat.

Angle ANM : Faire parler les chiffres avant qu’un contrôleur ne le fasse.

## Structure de base d’une publication

1. **L’accroche** — deux ou trois lignes maximum. Directe, immédiatement compréhensible.
   - « Votre sous-traitant vous transmet son attestation de vigilance. Vous pensez être protégé ? »
   - « 18 000 heures facturées. 11 000 heures produites par vos salariés. Où sont les 7 000 heures restantes ? »
   - « Le CNAPS sanctionne une entreprise. Le problème n’était pourtant pas celui que le dirigeant pensait. »
2. **Le fait** — entreprise ; administration concernée ; contrôle ; anomalie ; sanction ou décision. Toujours distinguer : faits / position de l’administration / arguments de l’entreprise / décision.
3. **Le point ANM** — dépasser le résumé. Ex. : « Ce dossier montre surtout que l’administration ne s’est pas limitée à vérifier l’existence des documents. Elle a rapproché plusieurs informations afin de vérifier la réalité de l’activité. »
4. **La question au dirigeant** — la signature ANM.
   - « Êtes-vous capable aujourd’hui de justifier la totalité des heures que vous facturez à vos clients ? »
   - « Savez-vous combien de salariés votre sous-traitant déclare réellement ? »
   - « Vos volumes sous-traités sont-ils cohérents avec les moyens humains déclarés par votre prestataire ? »
   - « Si un contrôleur rapproche vos factures, votre masse salariale et vos heures vendues, que verra-t-il ? »

## Ce qu’ANM peut dire, ce qu’il garde

ANM peut expliquer : le risque ; le mécanisme ; ce que l’administration regarde ; ce que la jurisprudence retient ; les conséquences possibles.

ANM ne doit pas systématiquement publier : la grille complète d’audit ; l’intégralité des contrôles à effectuer ; les méthodes précises de rapprochement ; toute la procédure corrective ; les outils internes ANM.

**Montrer où se trouve le risque sans donner gratuitement toute la méthode permettant de le neutraliser.**

Conclusion type : « La question n’est donc pas seulement de savoir si vos documents existent. Elle est de savoir s’ils résistent au rapprochement entre eux. »

Signature possible : ANM Consulting – Identifier les vulnérabilités avant le contrôle.

## Appels à l’action (à varier)

- Observatoire : « Décision et analyse complète dans l’Observatoire ANM. »
- Discussion : « Comment votre entreprise contrôle-t-elle aujourd’hui ce point ? »
- Diagnostic : « Vous souhaitez savoir comment ce risque se matérialiserait dans votre propre organisation ? »
- Audit : « ANM Consulting audite vos pratiques avant que l’administration ne le fasse. »

## Structure d’une fiche de l’Observatoire

1. référence exacte de la décision ;
2. faits ;
3. reproches de l’administration ;
4. défense de l’entreprise ;
5. décision rendue ;
6. point ANM ;
7. question adressée au dirigeant.

L’Observatoire ANM montre ce qui est arrivé aux autres. L’audit ANM répond à la question : cela pourrait-il arriver chez vous ?

## Par canal

**LinkedIn** : accroche courte ; cas réel ; analyse ANM ; question ; appel à l’action. Environ 800 à 1 500 caractères.

**Google et site ANM** — deux types de contenus :
- *Actualité chaude* : décisions ; sanctions ; nouvelles réglementations ; communications CNAPS ; décisions de tribunaux administratifs ; opérations URSSAF ; évolutions sociales et fiscales.
- *Contenu permanent*, par exemple :
  - Contrôle CNAPS : quels éléments sont vérifiés ?
  - Sous-traitance dans la sécurité privée : quelles obligations pour le donneur d’ordre ?
  - Attestation de vigilance : quelles limites ?
  - Contrôle URSSAF d’une société de sécurité : quels risques ?
  - Facturation et sous-traitance : dans quels cas la TVA peut-elle être remise en cause ?
  - Heures facturées et masse salariale : pourquoi les rapprocher ?
  - Travail dissimulé et sécurité privée : quels risques pour le donneur d’ordre ?

Chaque article doit conduire naturellement vers l’audit ANM.

**TikTok, Reels, Shorts** : ne pas reproduire LinkedIn. 0–5 s le problème ; 5–20 s le cas ; 20–40 s ce que l’administration regarde ; 40–50 s la question ANM ; 50–60 s l’appel à l’action. Séries : « 60 secondes avant le contrôle », « Le cas réel de la semaine », « Le chiffre qui ne colle pas », « Que verrait le contrôleur ? », « Vous êtes dirigeant : que voyez-vous ? ».

## Rythme

Quatre publications par semaine : lundi, le cas de la semaine (Observatoire) ; mardi, la question du dirigeant ; jeudi, le chiffre qui ne colle pas ; vendredi, 60 secondes avant le contrôle.

Sur 20 publications : 6 CNAPS ; 4 URSSAF ; 3 DGFIP ; 2 Inspection du travail / social ; 2 économie ; 2 décisions de justice transversales ; 1 publication directement commerciale.

## Veille

CNAPS ; tribunaux administratifs ; cours administratives d’appel ; Conseil d’État ; Cour de cassation ; URSSAF ; BOSS ; DGFIP ; Légifrance ; ministère du Travail ; GES Sécurité Privée ; organisations professionnelles ; presse professionnelle ; jurisprudence sociale et fiscale ; marchés publics lorsque pertinent.

## Ton

Direct ; factuel ; documenté ; lisible ; orienté dirigeant ; sans dramatisation artificielle. Ni professeur de droit, ni influenceur.

Éviter : « Attention ! Vous risquez très gros ! » Préférer : « Voici ce qu’un contrôleur pourrait constater. »

## Frontière avec le conseil juridique

ANM intervient sur : l’analyse des risques ; l’audit organisationnel ; l’audit documentaire ; la cohérence des processus ; la prévention ; l’identification des vulnérabilités ; l’accompagnement organisationnel.

Mention possible : « Cette publication présente une analyse générale à partir de sources publiques. Elle ne constitue pas une consultation juridique individualisée. »

## Les cinq questions avant chaque diffusion

1. Le sujet concerne-t-il réellement un dirigeant de sécurité privée ?
2. Existe-t-il un fait, un chiffre, une décision ou une source vérifiable ?
3. ANM apporte-t-il une analyse et non un simple résumé ?
4. La publication démontre-t-elle l’expertise sans dévoiler toute la méthode d’audit ?
5. Le lecteur comprend-il pourquoi ANM peut lui être utile ?

Si les cinq réponses sont positives, le contenu peut être publié.

## Phrase directrice

« Montrer au dirigeant ce que l’administration pourrait voir dans son entreprise avant qu’elle ne vienne le regarder elle-même. »
